# 読み物＋問題の生成手順（好みプロファイル → レベル別パック）

入力: `packs/<slug>/profile.json`（好み）＋ `rules/levels.json`（レベル規則）＋ 見本 `packs/animesensei/n5.json`。
出力: `packs/<slug>/<level>.json` 1ファイル。JSONだけを返す（前後に説明文を付けない）。
検品: `uv run --with janome python3 check.py <slug>` が ✗ 0 になるまで直す。

## 絶対ルール
1. 本文・問題はすべて新しく書く。既存の作品（小説・アニメ・市販教材）の文、登場人物、固有の設定、筋を使わない。
   ジャンルの型（異世界に行く・同じ日をやり直す・長いタイトル等）は使ってよい。作品名は profile の話題として触れる程度まで。
2. 生徒の名前・ハンドル名を本文・問題・ファイル名に入れない。登場人物は「わたし」「店長」「兄」など役割か、ありふれた架空の名字だけ。
3. 事実（年・数字・人名）を書くときは確実なものだけ。自信がなければ意見文・創作にする。
4. レベル規則（levels.json）の字数・文体・使ってよい文法・使えない文法を守る。N5〜N3 は全漢字にルビ `漢字{かんじ}`（{ }内はひらがな）。

## 書き方（段階別リーダーから取り入れた型）
- 書き出しは短い文。低いレベルほど時間の順に書く。主語を省きすぎない。登場人物は2〜3人まで。
- 背景知識が要る話は、本題の前に説明の段落を置く。
- 表にない語は、前後でわかる形で使い、2回以上出す。
- `lead` は1文の紹介文。「状況 → 事件の起こり → ……」で切るか、「〜でしょう？」と問いかける。
- `genre` にはシリーズ名や文章の種類（お知らせ・日記・メール・説明文・随筆・論説・創作）を書く。

## 問題の作り方（JLPT形式）
- セクションごとの問題数は levels.json の `q`。4択・正解は1つ。
- 聞くこと: 下線部の理由／指示語の中身／筆者の言いたいこと／条件に合うもの（情報検索）。
- 不正解の作り方（3つとも別の型にする）: 本文にない情報、時や主語のすり替え、本文の語句を使った部分一致、言い過ぎ。
- `ev`: 正解の根拠になる本文の一部を**ルビを外して一字一句そのまま**抜く（checkが照合する）。
- `why`: 正解の理由を1〜2文。`ng`: 4要素で、正解の位置だけ空文字 `""`、他は「なぜ違うか」を1文。
- 解説の言語: N5・N4 は英語、N3 以上はやさしい日本語（profile の `explain_lang` があればそれに従う）。
- `words`: 覚えたい語を2〜4個 `[語, よみ, 意味(英)]`。

## JSONの形
```json
{"level":"n4","passages":[{"id":"n4-01","type":"short","genre":"…","title":"…","lead":"…","text":"…","questions":[{"q":"…","c":["…","…","…","…"],"a":0,"ev":"…","why":"…","ng":["","…","…","…"]}],"words":[["…","…","…"]]}]}
```
`type` は levels.json の sections の type（short / mid / long / info / compare / opinion）。compare は `text` にA、`textB` にBを入れる。
情報検索（info）は表を改行と全角スペースで組む。
